# Diamond Order Profitability Simulator

A lightweight business analytics prototype designed to estimate the profitability of diamond manufacturing orders under different revenue, cost, overhead, and sensitivity assumptions.

## Purpose

Diamond manufacturing decisions are often driven by thin margins, volatile input costs, yield uncertainty, and client-specific pricing pressure. This simulator helps model how order economics change as assumptions shift.

The goal is to turn a simple order-level calculator into a more robust decision-support tool for evaluating manufacturing profitability.

## Current Features

- Order revenue estimation
- Rough stone cost input
- Polished output assumptions
- Overhead and processing cost logic
- Profitability and margin calculation
- Sensitivity scenario view
- Clean standalone HTML interface

## Why This Matters

In a low-margin manufacturing environment, small changes in rough prices, yield, labor, overhead, or polished diamond pricing can materially affect profitability. This tool is intended to make those tradeoffs easier to see before accepting or pricing an order.
